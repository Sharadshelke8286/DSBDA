# Data Analytics III - Naive Bayes on Iris Dataset

# Step 1: Import Libraries
import numpy as np
import pandas as pd
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import confusion_matrix, accuracy_score, precision_score, recall_score

# Step 2: Load Dataset
iris = load_iris()
X = iris.data       # Features
y = iris.target     # Labels

# Step 3: Split Dataset
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# Step 4: Apply Naive Bayes (GaussianNB)
model = GaussianNB()
model.fit(X_train, y_train)

# Step 5: Prediction
y_pred = model.predict(X_test)

# Step 6: Confusion Matrix
cm = confusion_matrix(y_test, y_pred)

# Step 7: Evaluation Metrics
accuracy = accuracy_score(y_test, y_pred)
error_rate = 1 - accuracy
precision = precision_score(y_test, y_pred, average='macro')
recall = recall_score(y_test, y_pred, average='macro')

# Step 8: Output Results
print("----- Confusion Matrix -----")
print(cm)

print("\n----- Evaluation Metrics -----")
print("Accuracy     :", accuracy)
print("Error Rate   :", error_rate)
print("Precision    :", precision)
print("Recall       :", recall)



1️⃣ What is Naïve Bayes?
Naïve Bayes is a probabilistic classification algorithm based on Bayes Theorem, assuming all features are independent.

2️⃣ Why is it called “Naïve”?
Because it assumes independence between features, which is not always true in real data.

3️⃣ What type of algorithm is Naïve Bayes?
It is a supervised machine learning classification algorithm.

4️⃣ What is the Iris dataset?
It is a multiclass dataset with 150 samples used for classification of flowers into:


Setosa


Versicolor


Virginica



🔹 Conceptual Questions
5️⃣ What is Bayes Theorem?
It calculates probability using prior knowledge:
P(A∣B)=P(B∣A)⋅P(A)P(B)P(A|B) = \frac{P(B|A)\cdot P(A)}{P(B)}P(A∣B)=P(B)P(B∣A)⋅P(A)​

6️⃣ What are prior and posterior probabilities?


Prior: Initial probability before seeing data


Posterior: Updated probability after considering evidence



7️⃣ What is Gaussian Naïve Bayes?
It assumes that features follow a normal (Gaussian) distribution, suitable for continuous data.

8️⃣ Why did you use GaussianNB in this practical?
Because the Iris dataset contains continuous numerical features.

🔹 Evaluation Questions
1️⃣2️⃣ What is a Confusion Matrix?
A table that shows actual vs predicted values.

1️⃣3️⃣ What do diagonal values represent?
They represent correct predictions.

1️⃣4️⃣ What is Accuracy?
Accuracy = Correct Predictions / Total Predictions

1️⃣5️⃣ What is Error Rate?
Error Rate = 1 − Accuracy

1️⃣6️⃣ What is Precision?
Precision = TP / (TP + FP)
It shows how many predicted values are correct.

1️⃣7️⃣ What is Recall?
Recall = TP / (TP + FN)
It shows how many actual values are correctly identified.

🔹 Advanced / Tricky Questions
1️⃣8️⃣ What are the advantages of Naïve Bayes?


Simple and fast


Works well on small datasets


Requires less training data



1️⃣9️⃣ What are the limitations?


Assumes feature independence


Not suitable if features are highly correlated

2️⃣1️⃣ What happens if features are dependent?

2️⃣2️⃣ Is Naïve Bayes sensitive to irrelevant features?
